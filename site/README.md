# Тропа и котомка

## Настройка психологического дневника

Скопируйте пример окружения и заполните данные OpenAI-совместимого провайдера:

```bash
cp .env.example .env
```

```env
LLM_BASE_URL=https://provider.example/v1
LLM_API_KEY=your-secret-key
LLM_MODEL=provider-model-name
```

`LLM_BASE_URL` может указывать как на корень `/v1`, так и сразу на endpoint
`/chat/completions`. Ключ читается только серверным маршрутом.

## Локальный запуск

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

## Docker

```bash
docker compose up --build
```

После запуска:

- игра доступна по адресу `http://localhost:3000`;
- общая аналитика по всем завершённым сессиям — `http://localhost:4000`.

Дневник появляется после прохождения рисования, лепки и музыки. До 12 последних
наблюдений хранятся в `localStorage` браузера. После полного набора заданий
обезличенный результат с идентификатором сессии сохраняется на сервере и входит
в групповую сводку. Провайдеру отправляются структурированные признаки действий;
изображения, аудиозаписи и идентифицирующие данные не отправляются.

Docker хранит общую статистику в именованном volume `analytics-data`, поэтому она
не пропадает при пересборке контейнеров.
